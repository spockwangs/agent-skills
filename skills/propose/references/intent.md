# Intent: <title>

## Problem

要解决什么问题，以及为什么要解决该问题。

## Proposal

从用户角度描述诉求：用户想要什么、解决之后是什么样子。只讲「要解决什么」，不涉及怎么实现。

## User stories

用户与系统的一次交互（一次会话）就是一个用户故事。同一次交互中的多个步骤属于同一个用户故事，不要拆到不同的故事里。

每个故事按下面的格式写：

### US-N：<故事标题>

交互步骤：
1. 我以XXX角色执行XXX动作
2. 系统执行XXX动作，记录XXX，返回XXX给XXX角色

约束：
- 应满足什么条件

异常：
- 输入非法时怎么办
- 系统在当前条件下无法执行指定的动作怎么办
