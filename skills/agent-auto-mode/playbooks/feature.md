# Feature

You own the design. Grill, plan, review and verify.

1. Call the skill `propose` to sharpen the intent and understand the problem.
2. Call the skill `design` to draft a spec so engineers can implement. Wait for the user to approve the spec.
3. Call the skill `implement` to implement according to the spec.
4. Verify the artifacts work as the spec required.
5. Open a PR.

**Reply**: changes and the proof that it works.
